# Council reviews

The structured output of external reviews of this repository, kept because each
one became a phase of work and the phase's head summarises rather than reproduces
it. One directory per review, named for when it ran.

| review | directory | what it became |
|---|---|---|
| 2026-09-20, the second external review of the `0.3.0` tree | [`20260920-161505/`](20260920-161505/) | **Phase 26** — four gaps, each measured against the code before it became a task; fourteen tasks, closed 2026-09-21 |

The third review (2026-09-21) arrived as prose rather than as files; it is in
[`../OPEN-ITEMS.md`](../OPEN-ITEMS.md) with a verdict under every item, and became
**Phase 27**.

These are *inputs*, not findings we stand behind: each review's claims were checked
against the tree before any became a task, and several did not survive that check.
The phase heads in [`tasks.md`](../../.kiro/specs/valvur/tasks.md) say which.

They live under `docs/` so they stay out of the published distribution — `/docs`
is excluded from the sdist, and until 2026-09-22 (task 27.2.3) these six files
shipped inside `valvur-0.3.0.tar.gz` because nothing said they should not.
