  and are still registered, `arpan-package` and `atez`, are on the malicious list
  (R11.5). Each is reported as `valvur.dependency.malicious`, critical, however it is
  declared.

  Before, it read three datasets from the last track only. It first read OSV as
  absent, because the last track read no OSV database; it now takes the oldest age
  any track read.

  first made a partial run fail it for a fixture it never scanned. It is now recorded,
  not judged, when unmeasured.
