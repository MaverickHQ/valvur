# Phase R21, findable: the record

Built in a Claude Code cloud session (D61): the VM is the local lane, GitHub's runners
the Linux lane, and the Mac lane is **pending**, held in `tasks.md` §8 for one run over
the landed stack.

## What shipped

- **The demo** (R21.1, D48a). `scripts/demo.py` scans acceptance repository 8 through
  the CLI and renders what it printed as `docs/demo.svg`, 1.9 KB, with the standard
  library alone. It shows `findings: 2 active` and `@hyperion-util/cookies was published
  as malicious (MAL-2023-1)`, and holds no path of this machine and no secret.
- **Ready to list** (R21.2, D48b). The README's *Privacy* and *Support*, and
  `docs/LISTING.md` drawn from the plugin's and the power's manifests.
- **The first run** (R21.3, D58). The plugin's two commands first, `uvx valvur scan`
  second; the allow rules in the README and the skill's `references/permissions.md`;
  the skill's *When a tool is refused*, with `! uvx valvur==1.3.1 scan`, which the
  release moves.
- **The loop closed** (R21.4, D59). A rescan's `SUMMARY.md` and `scan` reply open with
  every earlier finding by rule ID and path, `fixed`, `open` or `not re-checked`, then
  the new ones; the skill rescans and leads with it; `REMEDIATION.md` gives each
  unpinned action its `gh api` lookup and its `uses:` line.

## The hook under *don't ask*

Deferred by the cloud session (D61h), since it needs `claude -p` with the owner's login,
and **measured locally on 2026-10-04**, after R21 landed:
`scripts/acceptance/hook_smoke.py --permission-mode dontAsk`, with `Bash` allowed and
every installer and fetcher a recording stub, asked to install a made-up npm package.

- **Claude Code refuses the install.** In *don't ask* it cannot ask, so the hook's `ask`
  becomes `permission_denied`, with `decision_reason_type: "hook"` and the hook's
  reason, as it does under `-p` (R18.4). The model relayed the reason.
- **Nothing was installed:** the stubs recorded no call.
- **Cost:** $0.13 of D58's $2, on its own ledger. D58's fallback is not needed.
