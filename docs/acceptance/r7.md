# Phase R7, documents and `1.0.0`: the record

## The README's measurements (R7.1)

Every number the README cites is the acceptance set's or one of the code's limits
(`tests/test_readme_as_built.py`). These are the ones no earlier record held, taken
2026-09-28 on this Mac (Apple silicon, Docker Desktop, host swap 12.7 GB).

**A first scan from an empty cache.** `valvur scan` of a copy of acceptance repository 2
with `VALVUR_CACHE` pointing at an empty directory and the image already local: 59 s in
all, complete, 96 active findings. What it fetched, from `run.json`'s `network.fetched`:

| fetched | MB | seconds |
|---|---|---|
| the vulnerability database | 123 | 21.5 |
| the package-name index, signature verified | 36 | 8.3 |
| OSV's database for PyPI | 35 | 2.5 |
| OSV's database for npm | 217 | 6.0 |

The Scanners took the rest: OSV-Scanner 15.3 s, reading npm's database, and every other
under 6 s. The cache afterwards: 1.7 GB, of which the vulnerability database is 1.4 GB,
OSV's two databases 243 MB and the index 118 MB.

**The index.** 6,334,163 names, built 2026-09-27: npm 4,432,959, PyPI 900,170, Packagist
463,413, crates.io 340,644 and RubyGems 196,977.

**The image.** `valvur:dev` from this tree is 665 MB on disk. The published `0.5.0`'s
compressed layers, the size of a pull, sum to 256 MB on amd64 and 246 MB on arm64.
