judged, speed among them. Linux's run takes no acceptance report, so speed is recorded

**Found by this comparison, and fixed.** The first back-to-back pair reused on only
four tracks: a `--fresh` scan stored nothing. So a developer who doubted a reused
answer and ran `--fresh` got a new answer once, and the next scan reused the old one
again. A fresh scan now stores what it ran (`fix(r14.3)`, a test for it). The pair
above is the second, run after the fix.
