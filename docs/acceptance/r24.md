# Phase R24, the machinery made lighter: the record

Built in a Claude Code cloud session (D61): the VM is the local lane, GitHub's runners
the Linux lane, and the Mac lane is **pending**, held in `tasks.md` §8 for one run over
the landed stack.

## What shipped

- **Generated, not compared** (R24.2). `scripts/generate_docs.py` writes eight blocks in
  five files from the code. `tests/test_generated_docs.py` regenerates them and names
  any that differs. Five tests and half of a sixth that compared those facts with prose
  are gone, and the constraint suite keeps its 54.
- **No test writes the repository** (R24.3). `scripts/sync_skill.py` writes the skill's
  copies, and `prepare_release.py` runs it; `UPDATE_SKILL` is gone.
- **CI builds once** (R24.4). Three image builds per pull request, five before. One
  action reads the version and one files a failure's issue, and the eight required
  checks keep their names.
- **Planning IDs out of the way** (R24.5). The traceability check reads no archive, and
  `CONTRIBUTING.md` names tests for what they test and has comments cite ADRs and
  requirements.

## Against the exit

- **The prose-comparing tests R24.1 counted:** 80 tests read prose then, 76 now. The
  ones whose facts are now generated are gone: the tools reference, the skill's rules,
  the clients block, `PROTOCOL.md`'s paths and binaries, and the README's commands.
  The rest stay, each where the sentence is the contract. Examples: the README's
  measured numbers, its platform claims, the version on every surface, and the
  security policy's series.
- **At most three image builds per pull request:** three on #185, run 37155498359.
  Building took about 3.6 minutes, 5.3 before. The required checks finished 11.1
  minutes after the run started, 8.4 on #184. About half of that is the jobs waiting
  for the shared build; the other half is the e2e tests themselves running longer.
- **The Score unchanged on both lanes** and **CI green**: below.
