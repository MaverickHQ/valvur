# Phase R18, the install asks first: the record

## What shipped

- **`valvur.installs`** reads the packages an install command would install: npm, pnpm,
  yarn, bun, pip, uv, poetry, cargo, gem and composer, and `-r` files. It never takes a
  path, URL or git reference for a name, and reads a chain one command at a time.
- **`valvur-hook`** reads Claude Code's `PreToolUse` event. When a package is flagged, or
  cannot be checked for want of an index, it answers `ask` with each verdict; otherwise
  it says nothing. It never denies, never runs the command and opens no socket.
  Against the real index, 4.4 million npm names, it answers 50 names in 0.16 to 0.30 s.
- **The plugin's hook.** `hooks/hooks.json` runs `hooks/pre-tool-use.sh`, which starts
  valvur only when the command names an installer: the pinned `uvx` command costs about
  0.45 s warm, too much before every shell command. `claude plugin validate --strict`
  passes, and the pin moves with the release.
- **Kiro** gets no hook: its hooks can only allow or block, and powers cannot carry them
  (D44's fallback). The skill's rule stands alone there.

## The smoke run (D46)

`scripts/acceptance/hook_smoke.py`: `claude -p` with the plugin, the `Bash` tool allowed,
every installer, `curl` and `wget` a recording stub first on `PATH`, asked to install a
made-up npm package in an empty scratch directory.

- **The hook stopped the install.** Under `-p`, Claude Code turns the hook's `ask` into a
  `permission_denied` with `decision_reason_type: "hook"` and the hook's reason; the
  model received the reason and reported it. The hook documentation does not say this.
- **Nothing was installed:** the stubs recorded no install of the name.
- **Two runs:** the exploratory one, $0.69, and the script's, $0.38. D46 stands at $1.07
  of $5.
