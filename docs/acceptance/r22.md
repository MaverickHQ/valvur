## What shipped

  `ossf/scorecard-action` v2.4.4, pinned by commit, weekly and on every push to `main`,
  and publishes from `main` alone. The scorecard job holds `security-events: write` and
  `id-token: write` and only approved actions; a pull request that changes the workflow
  measures with publishing off and prints each check. The README shows the badge.

  criteria of the passing level with links to evidence.
- One cheap fix: CI's published-image check reads its registry token with `jq` rather
  than piping a download into `python3`.
