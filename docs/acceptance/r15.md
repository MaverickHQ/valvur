# Phase R15, the skill that runs the workflow, and where it ships: the record

## What shipped

- **The skill**, `valvur`, in the open Agent Skills format: `SKILL.md` and four
  references, in the package at `src/valvur/data/skills/valvur/`. Its frontmatter
  holds only the standard's fields. It names exactly the seven tools the server lists,
  and every command it names is in the CLI.
- **The rules, written once** in `valvur.agent_rules`. The handshake carries them in
  full, and its snapshot did not change. The skill's rules block is the handshake's
  text. `SUMMARY.md` carries them in short, in the nine lines it had.
- **The Claude Code plugin** in `plugins/valvur/`, listed by the repository's
  marketplace. `claude plugin validate --strict` passes both. The server is pinned to
  the release, and the skill is a byte-for-byte copy.
- **The Kiro power** in `powers/valvur/`, an Agent Plugin (kiro.dev's powers pages and
  the Agent Plugins 1.0.0 spec, read 2026-09-30). The server is Kiro's block as the
  spec allows it, and the skill is a copy. Kiro's probe replays through the power's
  own command.
- **`init --write`** writes the skill where Claude Code and Kiro read it, never over
  what is there. `doctor` says whether a project's copy is this version's.
