## Measured on the way

- **`check_package`'s speed:** 50 answers in 59 ms against the real index (4.4 million
  npm names), 8 ms warm, with no socket opened.
- **Private names in Ruby and Rust:** the tool called the private-registry cases
  nonexistent, since the binding is inside the manifest. `registries.for_manifest` now
  reads Gemfile `source` blocks and Cargo `registry` keys, and both cases answer
  `unknown`, naming the registry.

## The suites

- **The unit run** (`-m "not e2e and not timing"`): 1656 passed on the Mac; CI's lint,
  types and tests job and Python 3.11 and 3.13 pass on #165.
- **The e2e and timing run on the Mac:** 81 passed, 6 skipped, none failed, in 11.5
  minutes, on the image built from this tree.
- **CI's reproducibility job** ("two builds of one tree are one image") failed on
  `79ee351`, R12's first run, after passing on every run before it. Two builds without
  cache gave different digests. The one layer R12 changes, the package and its
  `.pyc` files, compiles byte-identically twice at one path when rebuilt as the
  Dockerfile does. The phase commit's CI run re-runs the job, and #165 carries its
  result.
