the path to OWASP (R30 to R37) parked in `tasks.md` §9, and the README, the documents
beside it and the GitHub page first (D78). R39 changes no detection, ranking or data, so
the Score was not run; every number the README and the guides cite is still held to the
records in this folder (`test_readme_as_built.py`).

## How it is held

- `test_readme_shape.py`: the README's sections in order, under 250 lines, every link and
  anchor resolving.
- `test_documents.py`: the index lists every document, the three files exist, the citation
  names the declared version, and every relative link in every live document resolves.
- `test_github_page.py`: the page's text within GitHub's limits, and the social preview at
  1280 by 640 and under 1 MB.
- Thirteen claim tests read the guide their claim moved to (`tests/user_docs.py`); nothing
  they held was dropped.
- CI on the pull request, and the local gate: 2,222 tests.

## Left open

- **The social preview's upload** is the owner's: GitHub's API cannot set it.
- **PyPI renders the README itself**, and the README's relative links and images do not
  resolve there. They did not before R39 either. A build-time rewrite to absolute links,
  in `hatch_build.py`, would fix it, and is the owner's call (§9).
